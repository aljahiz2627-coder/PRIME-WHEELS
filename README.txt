GARASI DRIFT — Website Company Profile

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder garasi_drift di Visual Studio Code.
3. Buka index.html menggunakan browser atau ekstensi Live Server.
4. Pastikan koneksi internet aktif untuk memuat Google Fonts dan foto dari Unsplash.

KUSTOMISASI
- Ganti nomor 6281234567890 pada index.html dan script.js dengan nomor WhatsApp bisnis.
- Ubah nama mobil, harga, deskripsi, dan foto pada index.html.
- Foto katalog dan hero menggunakan URL Unsplash sehingga membutuhkan internet.
- Harga dan unit pada katalog adalah contoh/demo, bukan penawaran aktual.
